# HyperF Understanding

Well, I challenged myself to understand how I can use a Hyperf project, because I need to learn this technology to work with
it from front end to back end. I know this front-end application wouldn’t necessarily need this kind of solution, but right now I want to build one to understand it better.

- Create a minimal interface to perform a basic CRUD for users;
- Create a minimal interface to work with an authentication method (JWT);
- Create a context that can be used as a cache layer with Redis;
- Create some situations to use queues and async jobs.

Before doing all of this, you can also search for more challenges to create on the Hyperf server.
